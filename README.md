# 알음알음

안양 동안구 학원 소개 안드로이드 앱(Flutter + Firebase).

- 설치 · 사용 안내, 사용 언어와 기술, 소스 수정 방법: [docs/수정가이드.md](docs/수정가이드.md)
- 앱 코드: `lib/` · 테스트: `test/` · Firestore 보안 규칙: `firestore.rules`
- 학원 목록 가져오기 도구: `tools/import_academies/` (원본: `docs/진행 상황 및 일정.csv`)
- 보안 규칙 테스트: `tools/rules_test/`

## 프로젝트 목적 및 저작권 안내 (Project Purpose & Copyright)

본 프로젝트 **알음알음(AlumAlum)**은 대학원 수업 및 학술 연구를 목적으로 개발 중인 비상업적 프로젝트입니다.
